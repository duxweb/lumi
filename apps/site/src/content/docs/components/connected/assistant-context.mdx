页面打开期间告诉外壳的助手这个页面是关于什么的：每个条目成为一个上下文块，读者发送前可以移除；页面关闭或条目变化时移除。不渲染任何内容，放在页面任意位置即可。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `items` | 要显示的条目列表。 字段：`id`、`label`、`kind?`、`icon?`、`description?`、`data?` | `object[]` |  |

## 事件与插槽

- 事件：无
- 插槽：无
