来自应用审计日志提供者的资源或单条记录的变更历史，显示为动态流：谁在什么时候创建、更新（含字段）、删除或导入了什么。每次写入该资源后刷新。放在 DetailPage 的侧栏或 DashboardCard 中。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `resource`（必填） | 数据资源名，如 `orders`。DataProvider 据此拼出接口地址。 | `string` |  |
| `id` | 记录 ID。填写时先按 ID 读取记录，保存时更新它；不填时是新建。 | `string \| number` |  |
| `pageSize` | 每页条数。 | `integer` |  |
| `dataProviderName` | 使用哪个 DataProvider。只有一个时不用填。 | `string` |  |
| `empty` | 没有数据时显示的文字。 | `string` |  |
| `ariaLabel` | 给读屏软件的名称。没有可见标签时必须填写。 | `string` |  |

## 事件与插槽

- 事件：无
- 插槽：无
