仪表盘面板：一个面板，带标题、可选的头部操作和底部一行文字。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `title`（必填） | 卡片标题。 | `string` |  |
| `description` | 标题下方的一行说明。 | `string` |  |
| `span` | `full` 占满整行；不填时占一列。 | `"full"` |  |
| `flush` | 去掉内边距，适合直接放表格或图表。 | `boolean` | `false` |

## 事件与插槽

- 事件：无
- 插槽：`default`、`action`、`footer`
