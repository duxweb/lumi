---
title: "DataGrid"
description: "受控的 Admin 结果网格，带分页。"
---

受控的 Admin 结果网格，带分页。`rowActions` 插槽里的元素会画在 `kind: "actions"` 列的每一行，各自绑定自己的动作；属性里用 `$item` 读这一行，动作执行前这一行会写入绑定的 `activeRow`，参数里用 `{ "$state": "/table/row/id" }` 读取。`bulkActions` 在网格上方显示勾选操作栏；`bulkAction` 把点击的值写入 `activeAction`。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `rows`（必填） | 表格数据。 | `object[]` |  |
| `columns`（必填） | 列定义，同 Table。 字段：`field`、`label?`、`width?`、`sortable?`、`align?`、`kind?`、`valueMap?`、`toneMap?`、`descriptionField?`、`imageField?`、`labelField?`、`initials?`、`truncate?`、`wrap?`、`currency?`、`actions?` | `object[]` |  |
| `bulkActions` | 勾选行后出现的批量操作按钮，每项 `{ action, label, tone? }`。 字段：`value`、`label`、`icon?`、`tone?`、`disabled?` | `object[]` |  |
| `visibleColumns` | 只显示这些字段对应的列，不填显示全部。 | `string[]` |  |
| `columnOrder` | 列的显示顺序，按字段名排列。 | `string[]` |  |
| `sorters` | 当前排序，每项 `{ field, order: "asc" \| "desc" }`。 字段：`field`、`order` | `object[]` |  |
| `rowKey` | 每行数据里用作唯一键的字段名。 | `string` | `"id"` |
| `highlightField` | 该字段为真值的行会高亮，如标记异常的订单。 | `string` |  |
| `loading` | 为 true 时显示加载状态，并暂停交互。 | `boolean` | `false` |
| `empty` | 没有数据时显示的文字。 字段：`title`、`description?`、`icon?` | `string \| object` |  |
| `showHeader` | 设为 `false` 时隐藏表头；表头仍保留给读屏器。 | `boolean` | `true` |
| `selectable` | 显示勾选列，可以多选行。 | `boolean` | `false` |
| `selectedKeys` | 已勾选行的键。写成 `{ "$bindState": "/路径" }` 即与页面状态双向绑定。 | `(string \| number)[]` | `[]` |
| `total`（必填） | 数据总条数，用于分页和合计显示。 | `number` |  |
| `summary` | 表格上方的简短摘要。 | `string` |  |
| `totals` | 表格底部的合计行，每项 `{ field, value }`。 字段：`label`、`value`、`emphasis?` | `object[]` |  |
| `activeRow` | 最近一次点击的行数据，供行操作读取。通常绑定到状态。 | `object` |  |
| `activeAction` | 最近一次点击的行操作名。通常绑定到状态。 | `string` |  |
| `page`（必填） | 当前页码。 | `integer` |  |
| `pageSize`（必填） | 每页条数。 | `integer` |  |
| `state` | 页面状态：加载中、空、出错、无权限等，`{ kind, title?, reason?, nextStep? }`。不填时正常显示内容。 字段：`kind`、`title`、`reason`、`nextStep`、`actionLabel?`、`disabled?` | `object` |  |
| `pageSizeOptions` | 可选的每页条数，如 `[10, 20, 50]`。不填则不显示切换。 | `number[]` |  |

通用参数：

- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：`pageChange`、`pageSizeChange`、`sort`、`selectionChange`、`rowClick`、`rowAction`、`bulkAction`
- 插槽：`rowActions`
