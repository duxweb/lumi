文档示例卡片：显示子元素的实际效果，代码视图把它们显示为原生 Spec。`id` 为卡片命名以便页内跳转（`#id`），在页面内必须唯一。代码视图读取页面 Spec，所以只出现在由 LumiSpecPage 渲染或位于 LumiSpecSource 之下的页面中。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `id`（必填） | 示例的锚点，页内链接 `#id` 跳到这里；同一页面内不能重复。 | `string` |  |
| `title`（必填） | 示例卡片的标题。 | `string` |  |
| `description` | 标题下方的一行说明。 | `string` |  |

通用参数：

- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。

## 事件与插槽

- 事件：无
- 插槽：`default`
