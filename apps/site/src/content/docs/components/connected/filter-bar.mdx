---
title: "FilterBar"
description: "Admin 筛选工具栏。"
---

Admin 筛选工具栏。把 value 绑定到查询的筛选条件。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `schema`（必填） | 筛选项定义：有哪些字段、各用什么控件（chips、select、cascader、dateRange 等）。 字段：`fields`、`presets?` | `object` |  |
| `applyMode`（必填） | `immediate` 改动后立即生效；`explicit` 点“应用”后才生效。 | `"immediate" \| "explicit"` | `"immediate"` |
| `value` | 当前筛选值。写成 `{ "$bindState": "/路径" }` 即与页面状态双向绑定。 | `object` |  |
| `defaultValue` | 初始值，只在没有绑定 `value` 时生效。 | `object` |  |
| `disabled` | 禁用，不可操作。 | `boolean` | `false` |
| `loading` | 为 true 时显示加载状态，并暂停交互。 | `boolean` | `false` |
| `title` | 筛选区标题，只给读屏软件。 | `string` |  |
| `description` | 标题下方的一行说明。 | `string` |  |

通用参数：

- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。

## 事件与插槽

- 事件：`change`
- 插槽：`toolbarStart`、`toolbarEnd`
