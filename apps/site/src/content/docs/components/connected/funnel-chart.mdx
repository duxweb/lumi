居中的转化漏斗：有序的阶段画成逐级变窄的色带，阶段间用梯形连接，颜色按调色板逐级变化。每个阶段显示数量和相对第一阶段的占比；每个连接显示相对上一阶段的转化率，悬停读数中显示流失。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `stages`（必填） | 按顺序排列的阶段，每项 `{ key, label, value, display? }`，第一项最宽。每个阶段显示数量和占第一阶段的百分比；连接段上显示相对上一阶段的转化率，悬停可看流失数。 字段：`key`、`label`、`value`、`display?` | `object[]` |  |
| `ariaLabel`（必填） | 给读屏软件的名称。没有可见标签时必须填写。 | `string` |  |
| `color` | 使用图表调色板里的第几种颜色（1–5），各阶段从全色逐级变浅。 | `1 \| 2 \| 3 \| 4 \| 5` | `1` |
| `scale` | 阶段宽度的换算：`sqrt` 按占比的平方根，首段大幅流失后小阶段仍清晰可读；`linear` 严格按比例。两种方式都有最小宽度（轨道的 24%），且宽度自上而下不会变宽。 | `"sqrt" \| "linear"` | `"sqrt"` |
