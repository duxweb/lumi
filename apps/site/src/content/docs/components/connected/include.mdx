在这个位置显示另一个 JSON 页面，用于多个页面共用的区块。第一次显示时才加载，按 src 缓存；它有自己独立的状态，params 在 /include/params 下，params 变化时重新开始。页面直接或间接引用自己，或者嵌套超过 8 层时显示错误。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `src`（必填） | 要显示的页面，写法和路由的 `page.src` 一样：站点路径、相对于 manifest 的路径，或配置了 `pages` 时交给页面接口的名字。 | `string` |  |
| `params` | 传给被引用页面的值，它在 `/include/params` 下读取，可以绑定状态，如 `{ "id": { "$state": "/route/params/id" } }`。值变化时被引用的页面重新开始。 | `object` |  |

## 事件与插槽

- 事件：无
- 插槽：无
