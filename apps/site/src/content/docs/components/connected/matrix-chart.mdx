按天数据的点阵趋势图，附带可被读屏软件读取的数值列表。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `points`（必填） | 数据点列表，每项至少有 `key`、`label`、`value`。 字段：`key`、`label`、`value`、`display?`、`note?` | `object[]` |  |
| `ariaLabel`（必填） | 给读屏软件的名称。没有可见标签时必须填写。 | `string` |  |
| `rows` | 每一列的点数，越多越精细。 | `integer` | `16` |
| `max` | 刻度上限；不填时从数据最大值向上取整。 | `number` |  |
| `labelEvery` | 每隔几个点显示一个横轴标签。 | `integer` | `7` |

## 事件与插槽

- 事件：无
- 插槽：无
