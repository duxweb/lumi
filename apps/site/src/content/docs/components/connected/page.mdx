Admin 页面容器。`stack` 用标准分段间距排开多个分段（卡片、网格、表格）。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `width` | 内容宽度：`content` 适合阅读，`wide` 适合表格，`full` 撑满。 | `"full" \| "content" \| "wide"` |  |
| `stack` | 多个区块（卡片、网格、表格）纵向排列，使用标准区块间距。 | `boolean` |  |
| `ariaLabel` | 给读屏软件的名称。没有可见标签时必须填写。 | `string` |  |

通用参数：

- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。

## 事件与插槽

- 事件：无
- 插槽：`default`
