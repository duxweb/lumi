工作在有序阶段中的堆积情况：把一个整体分在一根条中，如按状态分的订单。每个阶段都是上一阶段子集时用 FunnelChart。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `stages`（必填） | 阶段列表，每项 `{ key, label, value, tone? }`，按数量画成一条分段条，表示同一批对象的分布（如订单状态）。逐级转化请用 FunnelChart。 字段：`key`、`label`、`value`、`tone?` | `object[]` |  |
| `ariaLabel`（必填） | 给读屏软件的名称。没有可见标签时必须填写。 | `string` |  |

## 事件与插槽

- 事件：无
- 插槽：无
