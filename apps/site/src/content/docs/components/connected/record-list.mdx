紧凑的记录行，用于动态流、抽屉或仪表盘侧栏：标识、状态和一个数字，下方是元数据。`checked` 在前面加复选框（待办列表）；`progress` 在标题下加进度条。把 `items` 绑定到 Query 的数据；需要排序或分页的记录用 Table。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `items`（必填） | 记录列表，每项 `{ key, title, description?, meta?, progress? }`。 字段：`key`、`title`、`description?`、`status?`、`value?`、`meta?`、`checked?`、`progress?` | `object[]` |  |
| `title` | 列表标题。 | `string` |  |
| `ariaLabel` | 给读屏软件的名称。没有可见标签时必须填写。 | `string` |  |
| `loading` | 为 true 时显示加载状态，并暂停交互。 | `boolean` | `false` |
| `emptyLabel` | 没有数据时显示的文字。 | `string` |  |

## 事件与插槽

- 事件：无
- 插槽：无
