下方表格的合计，与表格行来自同一次查询快照。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `items`（必填） | 统计项，每项 `{ key, label, value, hint?, change?, tone? }`。 字段：`key`、`label`、`icon?`、`value`、`badge?`、`hint?`、`change?`、`series?`、`tone?` | `object[]` |  |
| `ariaLabel` | 给读屏软件的名称。没有可见标签时必须填写。 | `string` |  |

## 事件与插槽

- 事件：无
- 插槽：无
