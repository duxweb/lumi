---

侧栏树，把列表缩小到一个分支，放在 ListPage 的 `aside` 插槽中。把 `value` 绑定到 ListPage 筛选读取的状态路径（`eq`），或绑定 `subtree` 得到所选节点及其已加载的后代（`in`）。`null` 表示全部记录。节点来自静态 `items` 或 `source` 资源。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `items` | 要显示的条目列表。 | `object[]` |  |
| `source` | 从远程资源读取节点，如 `{ "resource": "categories", "labelField": "name", "lazy": true }`：默认按 `parentId` 组装成树，`lazy` 时逐级请求；已选值会按 ID 回显。设置后忽略静态节点。 字段：`resource`、`dataProviderName?`、`meta?`、`filters?`、`labelField?`、`valueField?`、`parentField?`、`childrenField?`、`leafField?`、`lazy?`、`rootValue?`、`searchField?`、`pageSize?` | `object` |  |
| `value` | 当前值。写成 `{ "$bindState": "/路径" }` 即与页面状态双向绑定。 | `string \| number \| null` |  |
| `subtree` | 选中节点及其已加载的所有下级节点值，适合列表的 `in` 筛选；选“全部”时为 `null`。写成 `{ "$bindState": "/路径" }` 即与页面状态双向绑定。 | `(string \| number)[] \| null` |  |
| `title` | 标题。 | `string` |  |
| `allLabel` | 清除筛选那一行的文字。 | `string` | `"全部"` |
| `showAll` | 在树上方显示“全部”行。 | `boolean` | `true` |
| `searchable` | 树上方显示搜索框。 | `boolean` | `false` |
| `defaultExpandAll` | 初始展开所有节点。 | `boolean` | `false` |
| `loading` | 为 true 时显示加载状态，并暂停交互。 | `boolean` | `false` |
| `ariaLabel` | 给读屏软件的名称。没有可见标签时必须填写。 | `string` |  |

## 事件与插槽

- 事件：`change`
- 插槽：无
