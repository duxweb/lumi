页面 JSON 里的 `type` 只能是下面这些组件。每个组件页有实时预览、可复制的 JSON 示例和完整参数表。

## 通用

| 组件 | 作用 |
| --- | --- |
| [`Button`](/components/ui/button/) | 触发一个动作。 |
| [`Badge`](/components/ui/badge/) | 语义色的简短状态或数量标签。 |
| [`Icon`](/components/ui/icon/) | 按名称显示图标：Lumi 名称如 `search`，或任意 HugeIcons 免费图标如 `delivery-truck-01`（或 `DeliveryTruck01Icon`）；不在内置集合里的名称首次使用时加载。 |
| [`Heading`](/components/ui/heading/) | 标题文字（h1-h4）。 |
| [`Text`](/components/ui/text/) | 段落文字，行宽适合阅读，与 json-render shadcn 的 Text 兼容。 |
| [`Avatar`](/components/ui/avatar/) | 一个人或账号：图片或首字母，底色按名字选取，没有描边。 |
| [`AvatarGroup`](/components/ui/avatar-group/) | 一组重叠的头像，表示一条记录涉及的人。 |
| [`CodeBlock`](/components/ui/code-block/) | 只读源码，支持 JSON、JavaScript/TypeScript（JSX/TSX）、CSS、HTML、Bash、Go、YAML、SQL 和 Markdown 的语法高亮；其他语言按纯文本显示。 |

## 布局

| 组件 | 作用 |
| --- | --- |
| [`Fragment`](/components/ui/fragment/) | 把子元素编成一组，不带外框。 |
| [`Card`](/components/ui/card/) | 卡片面板，可带标题、说明和头部图标。 |
| [`Stack`](/components/ui/stack/) | 弹性布局容器，与 json-render shadcn 的 Stack 兼容。 |
| [`Grid`](/components/ui/grid/) | 网格布局（1-6 列），与 json-render shadcn 的 Grid 兼容；自身宽度变窄时减少列数（每列至少 12rem），因此在抽屉、卡片和嵌入预览里也能用。 |
| [`Separator`](/components/ui/separator/) | 视觉分隔线。 |
| [`Frame`](/components/ui/frame/) | 通用盒子，提供内边距、底色和边框，在没有其他合适布局时使用。 |
| [`Page`](/components/connected/page/) | Admin 页面容器。 |
| [`PageHeader`](/components/connected/page-header/) | Admin 页面标题和操作插槽。 |
| [`PageFrame`](/components/connected/page-frame/) | 带组合插槽的 Admin 页面框架。 |

## 数据录入

| --- | --- |

| [`Checkbox`](/components/ui/checkbox/) | 带文字的单个开/关选项。 |

| [`RadioGroup`](/components/ui/radio-group/) | 单选，所有选项同时可见。 |

| [`FormField`](/components/ui/form-field/) | 一个带标签的字段：根据 `fieldType` 或 `widget` 选择控件，并显示帮助文字和错误。 |
| [`Upload`](/components/ui/upload/) | 上传文件，显示进度，可取消和重试。 |
| [`CodeEditor`](/components/ui/code-editor/) | 编辑源码，高亮与 CodeBlock 相同，带行号、括号匹配、自动缩进和撤销。 |
| [`TagsInput`](/components/ui/tags-input/) | 以可移除标签块表示的文字标签。 |
| [`ImageGrid`](/components/ui/image-grid/) | 基于绑定的 `{ url, thumbnail?, alt? }[]` 值显示图片格子，第一张是封面。 |
| [`Segmented`](/components/connected/segmented/) | 同一份数据的少量互斥视图；用 $bindState 绑定 value。 |

## 数据连接

| 组件 | 作用 |
| --- | --- |
| [`CanAccess`](/components/connected/can-access/) | 只有权限提供者允许对 `resource` 执行 `action` 时才渲染子元素，否则渲染 `fallback` 插槽（判断期间什么也不显示）。 |
| [`Query`](/components/connected/query/) | 挂载时、参数变化时读取数据；实时提供者推送了该资源的变更时也会重新读取（`liveMode`）。 |
