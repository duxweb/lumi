卡片面板，可带标题、说明和头部图标。`href` 让整张卡片成为链接，如快捷入口。

## 示例

```json
{
  "root": "card-21",
  "elements": {
    "card-21": {
      "type": "Card",
      "props": { "title": "Card", "description": "Content surface" },
      "children": []
    }
  }
}
```

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `title` | 卡片标题。 | `string` |  |
| `description` | 标题下方的一行说明。 | `string` |  |
| `appearance` | `outline` 描边，`filled` 浅色底。 | `"outline" \| "filled"` | `"outline"` |
| `icon` | 图标名，来自内置 HugeIcons 图标集，如 `download`、`receipt`。 | `string \| null` |  |
| `href` | 链接地址。设置后整张卡片可点击。 | `string \| null` |  |

通用参数：

- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：无
- 插槽：`default`、`headerEnd`
