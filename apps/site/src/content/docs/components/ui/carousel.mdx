滚动吸附轨道上的幻灯片，带上一张/下一张按钮和圆点。幻灯片来自 `items`（图片，可在上面叠加标题和说明）或子元素，每个一张。`perView` 同时显示多张。`autoplay` 每隔 `interval` 毫秒（默认 5000）前进，悬停和聚焦时暂停，提供暂停按钮，偏好减少动效时不自动播放。把 `value` 绑定到当前幻灯片序号；切换时触发 `change`。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `items` | 要显示的条目列表。 字段：`url`、`alt?`、`title?`、`description?` | `object[] \| null` |  |
| `aspectRatio` | 每张幻灯片的比例。 | `"1/1" \| "4/3" \| "3/2" \| "16/9" \| "21/9" \| null` | `"16/9"` |
| `perView` | 同时显示几张（1–4）。 | `integer \| null` | `1` |
| `autoplay` | 自动播放；悬停或聚焦时暂停，偏好减少动效时不播放。 | `boolean \| null` | `false` |
| `interval` | 自动播放的间隔（毫秒），至少 2000。 | `integer \| null` | `5000` |
| `loop` | 到最后一张后回到第一张。 | `boolean \| null` | `false` |
| `arrows` | 显示上一张/下一张按钮。 | `boolean \| null` | `true` |
| `dots` | 显示底部的分页圆点。 | `boolean \| null` | `true` |
| `value` | 当前值。写成 `{ "$bindState": "/路径" }` 即与页面状态双向绑定。 | `integer \| null` |  |

通用参数：

- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：`change`
- 插槽：`default`
