分级选择，每级一列（地区 → 城市，分类 → 子分类）。值是从根开始的选项值路径。`changeOnSelect` 允许选父级；`searchable` 按任意一级的文字查找路径。

## 示例

```json
{
  "root": "cascader-1",
  "elements": {
    "cascader-1": {
      "type": "Cascader",
      "props": {
        "value": { "$bindState": "/cascader-1/value" },
        "options": [
          {
            "label": "Zhejiang",
            "value": "zj",
            "children": [
              {
                "label": "Hangzhou",
                "value": "hz",
                "children": [
                  { "label": "West Lake", "value": "xh" },
                  { "label": "Binjiang", "value": "bj" }
                ]
              },
              { "label": "Ningbo", "value": "nb" }
            ]
          },
          {
            "label": "Guangdong",
            "value": "gd",
            "children": [
              {
                "label": "Shenzhen",
                "value": "sz",
                "children": [
                  { "label": "Nanshan", "value": "ns" },
                  { "label": "Futian", "value": "ft" }
                ]
              },
              { "label": "Guangzhou", "value": "gz" }
            ]
          },
          {
            "label": "Sichuan",
            "value": "sc",
            "disabled": true,
            "children": [{ "label": "Chengdu", "value": "cd" }]
          }
        ],
        "ariaLabel": "Region",
        "placeholder": "Choose a district"
      },
      "children": []
    }
  },
  "state": { "cascader-1": { "value": ["zj", "hz", "xh"] } }
}
```

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `options` | 选项树，每项 `{ label, value, disabled?, children? }`，`children` 打开下一列。 | `object[]` | `[]` |
| `value` | 从根到选中项的值路径，如 `["zj", "hz"]`。写成 `{ "$bindState": "/路径" }` 即与页面状态双向绑定。 | `(string \| number \| boolean)[]` |  |
| `defaultValue` | 初始路径。 | `(string \| number \| boolean)[]` | `[]` |
| `changeOnSelect` | 允许选中中间层级，而不是只能选到最末一级。 | `boolean` | `false` |
| `searchable` | 面板顶部显示搜索框，按任意一级的名称查找路径。 | `boolean` | `false` |
| `clearable` | 有值时显示清除按钮。 | `boolean` | `false` |
| `loading` | 为 true 时显示加载状态，并暂停交互。 | `boolean` | `false` |
| `separator` | 输入框里各级名称之间的分隔符。 | `string` | `" / "` |
| `placeholder` | 没有值时显示的提示文字。 | `string` |  |
| `size` | 尺寸：`sm` 紧凑，`md` 标准，`lg` 宽松。 | `"sm" \| "md" \| "lg"` | `"md"` |
| `appearance` | 外观：`outline` 描边，`filled` 浅色填充。 | `"outline" \| "filled"` | `"outline"` |
| `name` | 字段名，表单提交时作为这个值的键。 | `string` |  |
| `disabled` | 禁用，不可操作。 | `boolean` | `false` |
| `readonly` | 只读：可以查看和复制，不能修改。 | `boolean` | `false` |
| `invalid` | 标记为校验未通过，显示错误样式。通常由 FormField 自动设置。 | `boolean` | `false` |
| `ariaLabel` | 给读屏软件的名称。没有可见标签时必须填写。 | `string` |  |
| `source` | 从远程资源读取节点，如 `{ "resource": "categories", "labelField": "name", "lazy": true }`：默认按 `parentId` 组装成树，`lazy` 时逐级请求；已选值会按 ID 回显。设置后忽略静态节点。 字段：`resource`、`dataProviderName?`、`meta?`、`filters?`、`labelField?`、`valueField?`、`parentField?`、`childrenField?`、`leafField?`、`lazy?`、`rootValue?`、`searchField?`、`pageSize?` | `object` |  |

通用参数：

- `checks`：json-render 原生校验规则，如 `{ "type": "required", "message": "请填写" }`，提交或失焦时执行。
- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：`change`
- 插槽：无
