侧边面板，页面保持可见，用于详情和编辑表单。

## 示例

```json
{
  "root": "drawer-20",
  "elements": {
    "drawer-20": {
      "type": "Drawer",
      "props": { "open": true, "title": "Drawer", "side": "right" },
      "children": []
    }
  }
}
```

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `open` | 是否打开。写成 `{ "$bindState": "/路径" }` 即与页面状态双向绑定。 | `boolean` |  |
| `defaultOpen` | 初始是否打开，只在没有绑定 `open` 时生效。 | `boolean` | `false` |
| `title`（必填） | 抽屉标题。 | `string` |  |
| `description` | 头部标题下方的说明，与正文分开；正文前的说明文字写在这里。 | `string` |  |
| `side` | 从哪一侧滑出。 | `"left" \| "right" \| "top" \| "bottom"` | `"right"` |
| `size` | 抽屉宽度（左右滑出时）或高度（上下滑出时）。 | `"sm" \| "md" \| "lg"` | `"md"` |

通用参数：

- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：`openChange`
- 插槽：`default`、`footerStart`、`footerEnd`
