<ComponentPreview name="FormField" />

一个带标签的字段：根据 `fieldType` 或 `widget` 选择控件，并显示帮助文字和错误。

## 示例

```json
{
  "root": "formfield-15",
  "elements": {
    "formfield-15": {
      "type": "FormField",
      "props": {
        "name": "name",
        "label": "Name",
        "fieldType": "string",
        "value": { "$bindState": "/form-14/name" }
      },
      "children": []
    }
  },
  "state": { "form-14": { "name": "Lumi" } }
}
```

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `name`（必填） | 字段名，表单提交时作为这个值的键。 | `string` |  |
| `label` | 字段标签。 | `string` |  |
| `fieldType` | 数据类型。不填 `widget` 时据此选控件：`date` 用日期选择，`enum` 用下拉，`boolean` 用开关。 | `"string" \| "number" \| "boolean" \| "text" \| "date" \| "datetime" \| "time" \| "dateRange" \| "enum" \| "enumMulti" \| "relation" \| "relationMulti" \| "file" \| "richtext" \| "json" \| "color" \| "custom"` | `"string"` |
| `widget` | 指定控件，覆盖按 `fieldType` 自动选的那个。 | `"Input" \| "Textarea" \| "NumberInput" \| "Select" \| "MultiSelect" \| "Checkbox" \| "CheckboxGroup" \| "RadioGroup" \| "Switch" \| "DatePicker" \| "TimePicker" \| "DateTimePicker" \| "DateRangePicker" \| "Cascader" \| "Upload" \| "TagsInput"` |  |
| `required` | 显示必填标记，并在提交时检查非空。 | `boolean` | `false` |
| `error` | 错误提示文字，显示在控件下方。 | `string` |  |
| `errorDisplay` | 错误的显示方式。`inline` 把错误写在控件下方；`tooltip` 只把控件标为错误态，消息在悬停、聚焦和提交失败后浮在控件上方，不改变布局。 | `"inline" \| "tooltip"` | `"inline"` |
| `help` | 字段下方的帮助文字。 | `string` |  |
| `value` | 字段的值，类型取决于控件。写成 `{ "$bindState": "/路径" }` 即与页面状态双向绑定。 | `unknown` |  |
| `defaultValue` | 初始值，只在没有绑定 `value` 时生效。 | `unknown` |  |
| `options` | 可选项列表，每项 `{ label, value, disabled? }`。 字段：`label`、`value`、`disabled?`、`description?`、`children?` | `object[]` |  |
| `multiple` | 允许选择多个。 | `boolean` | `false` |
| `filterable` | 在下拉面板里显示搜索框，按标签过滤选项。 | `boolean` | `false` |
| `clearable` | 有值时显示清除按钮。 | `boolean` | `false` |
| `type` | 传给 Input 的原生输入类型，如 `email`。 | `string` |  |
| `mask` | `Input` 控件的输入格式，同 Input 的 `mask`。 | `string` |  |
| `unmask` | 配合 `mask`，值只保留用户输入的字符。 | `boolean` | `false` |
| `loading` | 为 true 时显示加载状态，并暂停交互。 | `boolean` | `false` |
| `rows` | 多行控件的可见行数。 | `number` |  |
| `autoResize` | 高度随内容自动增长，不出现滚动条。 | `boolean` | `false` |
| `min` | 数字或日期的最小值。 | `string \| number` |  |
| `max` | 数字或日期的最大值。 | `string \| number` |  |
| `step` | 每次增减的步长。 | `number` |  |
| `precision` | 保留的小数位数。 | `number` |  |
| `prefix` | 控件内、值之前的固定文字，如货币符号；不计入值。 | `string` |  |
| `suffix` | 控件内、值之后的固定文字，如单位；不计入值。 | `string` |  |
| `direction` | 选项类控件的排列方向。 | `"row" \| "column"` | `"column"` |
| `accept` | 允许的文件类型，同原生 `accept`，如 `image/*,.pdf`。 | `string` |  |
| `maxSize` | 单个文件的最大字节数，超出会提示并拒绝。 | `number` |  |
| `preview` | 显示已上传图片的缩略图。 | `boolean` | `false` |
| `placeholder` | 没有值时显示的提示文字。 | `string` |  |
| `size` | 尺寸：`sm` 紧凑，`md` 标准，`lg` 宽松。 | `"sm" \| "md" \| "lg"` | `"md"` |
| `appearance` | 外观：`outline` 描边，`filled` 浅色填充。 | `"outline" \| "filled"` | `"outline"` |
| `disabled` | 禁用，不可操作。 | `boolean` | `false` |
| `readonly` | 只读：可以查看和复制，不能修改。 | `boolean` | `false` |
| `invalid` | 标记为校验未通过，显示错误样式。通常由 FormField 自动设置。 | `boolean` | `false` |
| `ariaLabel` | 给读屏软件的名称。没有可见标签时必须填写。 | `string` |  |

通用参数：

- `checks`：json-render 原生校验规则，如 `{ "type": "required", "message": "请填写" }`，提交或失焦时执行。
- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：`change`
- 插槽：`default`
