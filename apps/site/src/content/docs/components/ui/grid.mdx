网格布局（1-6 列），与 json-render shadcn 的 Grid 兼容；自身宽度变窄时减少列数（每列至少 12rem），因此在抽屉、卡片和嵌入预览里也能用。`minColumnWidth`（px）改为按宽度放下尽可能多的列。`align: "stretch"` 让同一行的条目等高，如一排卡片。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `columns` | 固定列数（1–6）。 | `integer \| null` |  |
| `gap` | 格子之间的间距。 | `"sm" \| "md" \| "lg" \| "xl" \| null` |  |
| `minColumnWidth` | 每列最小宽度（像素），按宽度自动决定列数。与 `columns` 二选一。 | `number \| null` |  |
| `align` | `stretch` 让同一行的格子等高，适合一排卡片；默认 `start` 顶部对齐。 | `"start" \| "stretch" \| null` | `"start"` |

通用参数：

- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：无
- 插槽：`default`
