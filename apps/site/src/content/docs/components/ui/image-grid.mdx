<ComponentPreview name="ImageGrid" />

基于绑定的 `{ url, thumbnail?, alt? }[]` 值显示图片格子，第一张是封面。上传格和拖入文件都可添加图片，按 `accept`、`maxSize` 和 `max` 检查；每个文件显示进度并可取消，失败的保留为一个格子并可重试。拖动格子，或按 Space 再用方向键，调整顺序；“设为封面”把一张移到最前。上传本身由宿主服务完成；没有服务时所选文件只作为本地预览。

## 示例

```json
{
  "root": "imagegrid-1",
  "elements": {
    "imagegrid-1": {
      "type": "ImageGrid",
      "props": {
        "value": { "$bindState": "/imagegrid-1/value" },
        "max": 4,
        "maxSize": 5242880,
        "coverLabel": "Cover",
        "addLabel": "Upload image",
        "ariaLabel": "Product images"
      },
      "children": []
    }
  },
  "state": {
    "imagegrid-1": {
      "value": [
        {
          "url": "data:image/svg+xml;utf8,<svg xmlns='http://www.w3.org/2000/svg' width='8' height='8'><rect width='8' height='8' fill='%23cfc4b5'/></svg>",
          "alt": "Grey"
        },
        {
          "url": "data:image/svg+xml;utf8,<svg xmlns='http://www.w3.org/2000/svg' width='8' height='8'><rect width='8' height='8' fill='%23e2d7b8'/></svg>",
          "alt": "Oat"
        }
      ]
    }
  }
}
```

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `value` | 图片列表，每项 `{ url, thumbnail?, alt? }`，第一张是封面；拖动或键盘排序后按新顺序写回。只保存上传完成的地址，上传中与失败的文件只在组件内显示。写成 `{ "$bindState": "/路径" }` 即与页面状态双向绑定。 字段：`url`、`thumbnail?`、`alt?` | `object[]` | `[]` |
| `defaultValue` | 初始值，只在没有绑定 `value` 时生效。 字段：`url`、`thumbnail?`、`alt?` | `object[]` |  |
| `accept` | 文件选择器与拖入文件接受的类型；拖入的文件同样按它检查，不合格的显示为错误图块。 | `string` | `"image/*"` |
| `multiple` | 一次可以选择或拖入多张；关闭后每次只取第一张。 | `boolean` | `true` |
| `max` | 最多几张图片，上传中的也计入；到达后隐藏上传图块，并在下方显示“n/max”。 | `integer` |  |
| `maxSize` | 单张图片的字节上限，超出的直接拒绝，不会发送。 | `number` |  |
| `hint` | 替换自动生成的“类型 · 大小上限”说明文字。 | `string` |  |
| `coverLabel` | 第一张图上的角标文字。 | `string` | `"封面"` |
| `addLabel` | 上传图块的文字。 | `string` | `"上传图片"` |
| `loading` | 为 true 时显示加载状态，并暂停交互。 | `boolean` | `false` |
| `progress` | 整批上传时的共享进度（0–100），通常由上传服务写入。 | `number` |  |
| `name` | 字段名，表单提交时作为这个值的键。 | `string` |  |
| `error` | 错误提示文字，显示在控件下方。 | `string` |  |
| `disabled` | 禁用，不可操作。 | `boolean` | `false` |
| `readonly` | 只读：可以查看和复制，不能修改。 | `boolean` | `false` |
| `invalid` | 标记为校验未通过，显示错误样式。通常由 FormField 自动设置。 | `boolean` | `false` |
| `ariaLabel` | 给读屏软件的名称。没有可见标签时必须填写。 | `string` |  |
| `upload` | 上传参数，如 `{ url, fieldName }`，交给 Lumi 上传服务（Admin 装配）；与 Upload 同一个服务，逐张显示进度，可取消、失败可重试。不给时使用应用配置的默认上传地址。 字段：`sign?`、`url?`、`method?`、`fieldName?`、`data?`、`dataProviderName?` | `object` |  |

通用参数：

- `checks`：json-render 原生校验规则，如 `{ "type": "required", "message": "请填写" }`，提交或失焦时执行。
- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：`change`
- 插槽：无
