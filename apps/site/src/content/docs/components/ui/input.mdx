绑定到状态的单行文本输入。支持前缀、后缀和清除按钮。

## 示例

```json
{
  "root": "input-3",
  "elements": {
    "input-3": {
      "type": "Input",
      "props": {
        "value": { "$bindState": "/input-3/value" },
        "placeholder": "Name",
        "ariaLabel": "Name"
      },
      "children": []
    }
  },
  "state": { "input-3": { "value": "Lumi" } }
}
```

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `value` | 当前值。写成 `{ "$bindState": "/路径" }` 即与页面状态双向绑定。 | `string \| number` |  |
| `defaultValue` | 初始值，只在没有绑定 `value` 时生效。 | `string \| number` |  |
| `type` | 原生输入类型，如 `text`、`email`、`password`、`search`。 | `string` | `"text"` |
| `clearable` | 有值时显示清除按钮。 | `boolean` | `false` |
| `mask` | 输入格式：`9` 一位数字，`A` 一个字母，`*` 两者皆可，其余字符自动补入，如 `999-9999-9999`。 | `string` |  |
| `unmask` | 配合 `mask`，绑定的值只保留用户输入的字符，不含格式符号。 | `boolean` | `false` |
| `prefix` | 输入框内、值之前的固定文字，如网址路径或货币符号；不计入值。 | `string` |  |
| `suffix` | 输入框内、值之后的固定文字，如单位或域名；不计入值。 | `string` |  |
| `placeholder` | 没有值时显示的提示文字。 | `string` |  |
| `size` | 尺寸：`sm` 紧凑，`md` 标准，`lg` 宽松。 | `"sm" \| "md" \| "lg"` | `"md"` |
| `appearance` | 外观：`outline` 描边，`filled` 浅色填充。 | `"outline" \| "filled"` | `"outline"` |
| `name` | 字段名，表单提交时作为这个值的键。 | `string` |  |
| `disabled` | 禁用，不可操作。 | `boolean` | `false` |
| `readonly` | 只读：可以查看和复制，不能修改。 | `boolean` | `false` |
| `invalid` | 标记为校验未通过，显示错误样式。通常由 FormField 自动设置。 | `boolean` | `false` |
| `ariaLabel` | 给读屏软件的名称。没有可见标签时必须填写。 | `string` |  |

通用参数：

- `checks`：json-render 原生校验规则，如 `{ "type": "required", "message": "请填写" }`，提交或失焦时执行。
- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：`change`
- 插槽：无
