<ComponentPreview name="Kbd" />

把键盘快捷键显示成按键块：单个按键，或 `["⌘", "K"]` 这样的组合。修饰键符号按名称朗读。

## 示例

```json
{
  "root": "kbd-34",
  "elements": {
    "kbd-34": { "type": "Kbd", "props": { "keys": ["⌘", "K"] }, "children": [] }
  }
}
```

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `keys`（必填） | 按键列表，每个键一个键帽，如 `["⌘", "K"]`。 | `string[]` |  |
| `separator` | 键帽之间的文字，如 `+` 或 `然后`。不填时并排显示。 | `string \| null` |  |
| `size` | 尺寸：`sm` 紧凑，`md` 标准，`lg` 宽松。 | `"sm" \| "md" \| null` | `"md"` |

通用参数：

- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：无
- 插槽：无
