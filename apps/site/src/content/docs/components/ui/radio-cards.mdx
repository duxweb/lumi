以卡片形式单选，每张卡片有图标、标题、说明，可加徽标或右侧文字（如价格）。方向键在卡片间移动。适合套餐、配送方式等需要解释的选择。

## 示例

```json
{
  "root": "radiocards-1",
  "elements": {
    "radiocards-1": {
      "type": "RadioCards",
      "props": {
        "options": [
          {
            "value": "starter",
            "label": "Starter",
            "description": "For one person.",
            "icon": "user",
            "extra": "$0"
          },
          {
            "value": "team",
            "label": "Team",
            "description": "Shared projects.",
            "icon": "user-group",
            "badge": "Popular",
            "extra": "$12"
          }
        ],
        "ariaLabel": "Plan",
        "value": { "$bindState": "/radiocards-1/value" }
      },
      "children": []
    }
  },
  "state": { "radiocards-1": { "value": "team" } }
}
```

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `value` | 当前值。写成 `{ "$bindState": "/路径" }` 即与页面状态双向绑定。 | `string \| number \| boolean` |  |
| `defaultValue` | 初始值，只在没有绑定 `value` 时生效。 | `string \| number \| boolean` |  |
| `options`（必填） | 可选项列表，每项 `{ label, value, disabled? }`。 字段：`value`、`label`、`description?`、`icon?`、`badge?`、`extra?`、`disabled?` | `object[]` |  |
| `columns` | 每行最多几张卡片；卡片会窄于最小宽度时自动减少。不填时按最小宽度排满。 | `integer` |  |
| `size` | 尺寸：`sm` 紧凑，`md` 标准，`lg` 宽松。 | `"sm" \| "md" \| "lg"` | `"md"` |
| `indicator` | 在卡片角落显示单选圆点。 | `boolean` | `true` |
| `name` | 字段名，表单提交时作为这个值的键。 | `string` |  |
| `disabled` | 禁用，不可操作。 | `boolean` | `false` |
| `readonly` | 只读：可以查看和复制，不能修改。 | `boolean` | `false` |
| `invalid` | 标记为校验未通过，显示错误样式。通常由 FormField 自动设置。 | `boolean` | `false` |
| `error` | 错误提示文字，显示在控件下方。 | `string` |  |
| `ariaLabel` | 给读屏软件的名称。没有可见标签时必须填写。 | `string` |  |

通用参数：

- `checks`：json-render 原生校验规则，如 `{ "type": "required", "message": "请填写" }`，提交或失焦时执行。
- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：`change`
- 插槽：无
