<ComponentPreview name="Repeater" />

基于绑定数组的可重复行（订单明细、联系人），以可编辑表格或卡片显示，支持添加、复制、删除、拖动手柄（或其方向键）排序、最少/最多行数、计算列、底部合计和单元格错误。在 Repeater 上写原生的 `repeat: { statePath, key }`，放一个 `RepeaterRow` 子元素，其子元素用 `$bindItem` 绑定单元格。

## 示例

```json
{
  "root": "repeater-lines",
  "elements": {
    "repeater-lines": {
      "type": "Repeater",
      "props": {
        "value": { "$bindState": "/lines/items" },
        "rowKey": "id",
        "min": 1,
        "max": 6,
        "ariaLabel": "Order lines",
        "columns": [
          { "key": "product", "label": "Product", "required": true },
          { "key": "qty", "label": "Qty", "width": 110 },
          {
            "key": "price",
            "label": "Unit price",
            "width": 140,
            "prefix": "$",
            "precision": 2
          },
          {
            "key": "total",
            "label": "Line total",
            "width": 130,
            "align": "end",
            "prefix": "$",
            "precision": 2,
            "compute": { "op": "product", "fields": ["qty", "price"] }
          }
        ],
        "summary": [
          { "key": "qty", "op": "sum" },
          { "key": "total", "op": "sum" }
        ],
        "newRow": { "product": "", "qty": 1, "price": 0 },
        "addLabel": "Add line"
      },
      "repeat": { "statePath": "/lines/items", "key": "id" },
      "children": ["repeater-line"]
    },
    "repeater-line": {
      "type": "RepeaterRow",
      "props": {},
      "children": [
        "repeater-line-product",
        "repeater-line-qty",
        "repeater-line-price"
      ]
    },
    "repeater-line-product": {
      "type": "Input",
      "props": { "ariaLabel": "Product", "value": { "$bindItem": "product" } }
    },
    "repeater-line-qty": {
      "type": "NumberInput",
      "props": { "ariaLabel": "Qty", "min": 1, "value": { "$bindItem": "qty" } }
    },
    "repeater-line-price": {
      "type": "NumberInput",
      "props": {
        "ariaLabel": "Price",
        "min": 0,
        "value": { "$bindItem": "price" }
      }
    }
  },
  "state": {
    "lines": {
      "items": [
        { "id": "l1", "product": "Wireless mouse", "qty": 2, "price": 39 },
        { "id": "l2", "product": "USB-C hub", "qty": 1, "price": 59 }
      ]
    }
  }
}
```

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `value` | 行数组，每行一个对象。配合元素级 `repeat` 渲染行，单元格用 `$bindItem` 绑定。写成 `{ "$bindState": "/路径" }` 即与页面状态双向绑定。 | `object[]` | `[]` |
| `layout` | `table` 表格内联单元格，`card` 每行一张卡片。 | `"table" \| "card"` | `"table"` |
| `columns`（必填） | 列定义，每项 `{ key, label, width?, align?, required?, span?, compute?, precision?, prefix?, suffix?, errorDisplay? }`。`RepeaterRow` 的子元素按顺序对应没有 `compute` 的列；`compute: { op: "product" \| "sum", fields }` 由其他字段计算。 字段：`key`、`label`、`width?`、`align?`、`required?`、`span?`、`compute?`、`precision?`、`prefix?`、`suffix?`、`errorDisplay?` | `object[]` |  |
| `summary` | 合计行，每项 `{ key, op }`，`op` 为 `sum`、`avg`、`min`、`max` 或 `count`。 字段：`key`、`op` | `object[]` |  |
| `summaryLabel` | 合计行第一格的文字。 | `string` | `"合计"` |
| `min` | 最少保留几行，到达时不能再删除。 | `integer` | `0` |
| `max` | 最多几行，到达时不能再添加或复制。 | `integer` |  |
| `newRow` | 新增行的初始值，如 `{ "qty": 1 }`。数字单元格应给初值以保持受控。 | `object` |  |
| `rowKey` | 行身份字段名。新增或复制的行会自动生成值；与 `repeat.key` 一致才能在排序时保留焦点。 | `string` | `"id"` |
| `sortable` | 显示拖动手柄；手柄聚焦时可用 ↑/↓ 移动一行，Home/End 移到首行/末行。 | `boolean` | `true` |
| `addable` | 显示“添加一行”按钮。 | `boolean` | `true` |
| `removable` | 每行显示删除按钮。 | `boolean` | `true` |
| `duplicable` | 每行显示复制按钮。 | `boolean` | `true` |
| `addLabel` | 添加按钮的文字。 | `string` |  |
| `rowLabel` | 卡片布局的行标题，`{index}` 替换为从 1 开始的行号。 | `string` |  |
| `emptyText` | 没有行时显示的文字。 | `string` |  |
| `errors` | 字段错误，键是 `name.行号.字段`（如 `items.2.qty`），通常绑定 submitForm 的 `fieldErrors`。排序、删除时错误随行移动，编辑单元格后对应错误清除。 | `object` |  |
| `name` | 错误路径的前缀，与提交值里的数组字段名一致。 | `string` |  |
| `errorDisplay` | 单元格错误的显示方式。表格布局默认 `tooltip`：行高不变，消息浮在出错单元格上方；卡片布局默认 `inline`：写在控件下方。列上的 `errorDisplay` 可单独覆盖。 | `"inline" \| "tooltip"` | `表格 "tooltip"，卡片 "inline"` |
| `disabled` | 禁用，不可操作。 | `boolean` | `false` |
| `readonly` | 只读：可以查看和复制，不能修改。 | `boolean` | `false` |
| `ariaLabel` | 给读屏软件的名称。没有可见标签时必须填写。 | `string` |  |

通用参数：

- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。

## 事件与插槽

- 事件：`change`
- 插槽：`default`
