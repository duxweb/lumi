在固定或最大高度内滚动子元素，可纵向、横向或双向，滚动条细窄且跟随主题。视口可以获得键盘焦点；用 `ariaLabel` 给它命名。

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `orientation` | 方向：`horizontal` 横向，`vertical` 纵向。 | `"vertical" \| "horizontal" \| "both" \| null` | `"horizontal"` |
| `maxHeight` | 最大高度，像素数字或 CSS 长度；超出时滚动。 | `number \| string \| null` |  |
| `height` | 固定高度，像素数字或 CSS 长度。 | `number \| string \| null` |  |
| `ariaLabel` | 给读屏软件的名称。没有可见标签时必须填写。 | `string \| null` |  |

通用参数：

- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：无
- 插槽：`default`
