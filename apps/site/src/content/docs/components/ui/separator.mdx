视觉分隔线。

## 示例

```json
{
  "root": "stk-sep",
  "elements": {
    "stk-sep": { "type": "Separator", "props": {}, "children": [] }
  }
}
```

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `orientation` | 分隔线方向。 | `"horizontal" \| "vertical" \| null` | `"horizontal"` |

通用参数：

- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：无
- 插槽：无
