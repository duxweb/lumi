<ComponentPreview name="TagGroup" />

绑定到数组的一行标签。没有 `options` 时每个值是一个可关闭的标签，移除即更新 `value`。有 `options` 时标签是可选的块，点击在 `value` 中加入或移除对应值（`multiple: false` 时最多选一个）。

## 示例

```json
{
  "root": "taggroup-37",
  "elements": {
    "taggroup-37": {
      "type": "TagGroup",
      "props": {
        "value": { "$bindState": "/taggroup-37/value" },
        "labels": {
          "design": "Design",
          "backend": "Backend",
          "ops": "Operations"
        },
        "ariaLabel": "Teams"
      },
      "children": []
    }
  },
  "state": { "taggroup-37": { "value": ["design", "backend", "ops"] } }
}
```

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `value` | 当前值。写成 `{ "$bindState": "/路径" }` 即与页面状态双向绑定。 | `(string \| number \| boolean)[]` |  |
| `defaultValue` | 初始值，只在没有绑定 `value` 时生效。 | `(string \| number \| boolean)[]` |  |
| `options` | 可选项列表，每项 `{ label, value, disabled? }`。 字段：`label`、`value`、`tone?`、`icon?`、`disabled?` | `object[] \| null` |  |
| `multiple` | 允许选择多个。 | `boolean \| null` | `false` |
| `labels` | 没有 `options` 时各值的显示文字，如 `{ "vip": "VIP 客户" }`。不填时直接显示值。 | `object \| null` |  |
| `tone` | 语义色：`success` 成功，`warning` 警告，`danger` 危险，`info` 提示，`neutral` 中性。 | `"neutral" \| "primary" \| "success" \| "warning" \| "danger" \| "info" \| "brand" \| null` | `"neutral"` |
| `appearance` | 外观：`outline` 描边，`filled` 浅色填充。 | `"soft" \| "solid" \| "outline" \| null` | `"outline"` |
| `size` | 尺寸：`sm` 紧凑，`md` 标准，`lg` 宽松。 | `"sm" \| "md" \| "lg" \| null` | `"md"` |
| `closable` | 没有 `options` 时每个标签显示删除按钮，删除即从 `value` 移除。 | `boolean \| null` | `true` |
| `empty` | 没有数据时显示的文字。 | `string \| null` |  |
| `disabled` | 禁用，不可操作。 | `boolean \| null` | `false` |
| `ariaLabel` | 给读屏软件的名称。没有可见标签时必须填写。 | `string \| null` |  |

通用参数：

- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：`change`
- 插槽：无
