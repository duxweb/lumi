<ComponentPreview name="Tag" />

紧凑的标签，标注分类、人员或筛选条件，色调和外观与 Badge 相同。`closable` 加一个移除按钮，点击时触发 `close`。`checkable` 把它变成可切换的标签：绑定 `checked`（`{ "$bindState": "/path" }`），点击切换并触发 `change`。

## 示例

```json
{
  "root": "tag-36",
  "elements": {
    "tag-36": {
      "type": "Tag",
      "props": {
        "label": "VIP customer",
        "tone": "brand",
        "icon": "star",
        "closable": true
      },
      "children": []
    }
  }
}
```

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `label`（必填） | 显示的文字。 | `string` |  |
| `tone` | 语义色：`success` 成功，`warning` 警告，`danger` 危险，`info` 提示，`neutral` 中性。 | `"neutral" \| "primary" \| "success" \| "warning" \| "danger" \| "info" \| "brand" \| null` | `"neutral"` |
| `appearance` | 外观：`outline` 描边，`filled` 浅色填充。 | `"soft" \| "solid" \| "outline" \| null` | `"outline"` |
| `size` | 尺寸：`sm` 紧凑，`md` 标准，`lg` 宽松。 | `"sm" \| "md" \| "lg" \| null` | `"md"` |
| `icon` | 图标名，来自内置 HugeIcons 图标集，如 `download`、`receipt`。 | `string \| null` |  |
| `avatar` | 标签前的头像 `{ name, src? }`，`name` 用于首字母和读屏名称。 字段：`name`、`src?` | `object \| null` |  |
| `dot` | 标签前显示语义色小圆点。 | `boolean \| null` | `false` |
| `closable` | 显示删除按钮，点击触发 `close` 事件。 | `boolean \| null` | `false` |
| `checkable` | 可切换的标签：点击翻转 `checked` 并触发 `change`。 | `boolean \| null` | `false` |
| `checked` | `checkable` 时是否选中。写成 `{ "$bindState": "/路径" }` 即与页面状态双向绑定。 | `boolean \| null` | `false` |
| `disabled` | 禁用，不可操作。 | `boolean \| null` | `false` |

通用参数：

- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：`close`、`change`
- 插槽：无
