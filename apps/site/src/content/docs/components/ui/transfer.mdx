两个列表——可选和已选——各带搜索、全选和计数；箭头按钮把勾选的条目移到另一侧。值是已选选项值的数组。

## 示例

```json
{
  "root": "transfer-48",
  "elements": {
    "transfer-48": {
      "type": "Transfer",
      "props": {
        "value": { "$bindState": "/transfer-48/value" },
        "options": [
          { "label": "Ada Lovelace", "value": "ada" },
          { "label": "Alan Turing", "value": "alan" },
          { "label": "Grace Hopper", "value": "grace" },
          { "label": "Linus Torvalds", "value": "linus" }
        ],
        "sourceTitle": "Available",
        "targetTitle": "Reviewers",
        "ariaLabel": "Reviewers"
      },
      "children": []
    }
  },
  "state": { "transfer-48": { "value": ["grace"] } }
}
```

## 参数

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `value` | 当前值。写成 `{ "$bindState": "/路径" }` 即与页面状态双向绑定。 | `(string \| number \| boolean)[]` |  |
| `defaultValue` | 初始值，只在没有绑定 `value` 时生效。 | `(string \| number \| boolean)[]` |  |
| `options` | 可选项列表，每项 `{ label, value, disabled? }`。 字段：`label`、`value`、`disabled?`、`description?`、`avatar?`、`image?` | `object[]` |  |
| `selectedOptions` | 已选值对应的选项，用于回显不在当前 `options` 里的值。使用 `source` 时自动提供。 字段：`label`、`value`、`disabled?`、`description?`、`avatar?`、`image?` | `object[]` |  |
| `sourceTitle` | 左侧（可选项）列表的标题。 | `string` | `"可选"` |
| `targetTitle` | 右侧（已选）列表的标题。 | `string` | `"已选"` |
| `filterable` | 在下拉面板里显示搜索框，按标签过滤选项。 | `boolean` | `false` |
| `loading` | 为 true 时显示加载状态，并暂停交互。 | `boolean` | `false` |
| `loadingMore` | 正在加载下一页，列表底部显示加载行。 | `boolean` | `false` |
| `hasMore` | 还有下一页；滚动到列表底部时触发加载。 | `boolean` | `false` |
| `total` | 数据总条数，用于分页和合计显示。 | `integer` |  |
| `name` | 字段名，表单提交时作为这个值的键。 | `string` |  |
| `disabled` | 禁用，不可操作。 | `boolean` | `false` |
| `readonly` | 只读：可以查看和复制，不能修改。 | `boolean` | `false` |
| `invalid` | 标记为校验未通过，显示错误样式。通常由 FormField 自动设置。 | `boolean` | `false` |
| `ariaLabel` | 给读屏软件的名称。没有可见标签时必须填写。 | `string` |  |
| `source` | 从远程资源读取选项（Lumi Admin），如 `{ "resource": "members", "labelField": "name", "searchField": "name", "dependsOn": { "parentId": "/form/province" } }`：支持远程搜索、滚动加载、按 ID 回显已选值和联动。设置后忽略静态 `options`。 字段：`resource`、`dataProviderName?`、`meta?`、`filters?`、`labelField?`、`valueField?`、`descriptionField?`、`avatarField?`、`imageField?`、`searchField?`、`pageSize?`、`dependsOn?`、`clearOnDependencyChange?` | `object` |  |

通用参数：

- `checks`：json-render 原生校验规则，如 `{ "type": "required", "message": "请填写" }`，提交或失焦时执行。
- `className`：附加的 CSS 类名，只在宿主自定义样式时使用。
- `data-testid`：测试定位用的标识，不影响显示。
- `aria-label`：原生 aria-label，等同于 `ariaLabel`。

## 事件与插槽

- 事件：`change`
- 插槽：无
