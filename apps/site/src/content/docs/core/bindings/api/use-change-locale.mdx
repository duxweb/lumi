---
title: "useChangeLocale"
description: "useChangeLocale React hook 的签名、参数和返回值。"
---

Returns `changeLocale(locale)`, which switches the i18n provider's locale.

```typescript
useChangeLocale(): (locale: string, params?: unknown) => Promise<void>
```

返回 `(locale: string, params?: unknown) => Promise<void>`。
