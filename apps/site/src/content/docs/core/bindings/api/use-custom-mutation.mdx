---
title: "useCustomMutation"
description: "useCustomMutation React hook 的签名、参数和返回值。"
---

Writes through the provider's `custom`: `build` turns the mutation's variables into the request, and `resource`, when given, is refetched after it succeeds.

```typescript
useCustomMutation<T = any, V = any>(options: Omit<MutationOptions<SingleResult<T>, V>, "resource"> & { resource?: string; build: (variables: V) => Omit<CustomParams, "signal">; }): UseMutationResult<SingleResult<T>, Error, V>
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `options` | `Omit<MutationOptions<SingleResult<T>, V>, "resource"> & { resource?: string; build: (variables: V) => Omit<CustomParams, "signal">; }` | 是 |  |

`options` 的字段：

| 名称 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `build` | `(variables: V) => Omit<CustomParams, "signal">` | 是 |  |
| `dataProviderName` | `string \| undefined` | 否 | 多数据源名称；省略时使用 default。 |
| `meta` | `Meta \| undefined` | 否 | 原样传给 DataProvider 的扩展数据。 |
| `mutationMode` | `MutationMode \| undefined` | 否 | Updates and deletes only: `optimistic` shows the change at once and rolls it back on failure; `undoable` also waits `undoableTimeout` with an Undo notice before sending (Undo rejects with MutationUndoneError, unreported). Defaults to the context's `mutationMode`, else `pessimistic`. |
| `onError` | `((error: Error, variables: V) => void \| Promise<void>) \| undefined` | 否 | Replaces the default report: without it a failure is shown as a danger toast. |
| `onSuccess` | `((data: SingleResult<T>, variables: V) => void \| Promise<void>) \| undefined` | 否 | Called with the saved data once the write succeeded. |
| `resource` | `string \| undefined` | 否 | 交给 DataProvider 解释的数据目标，如 `orders`。 |
| `undoableTimeout` | `number \| undefined` | 否 | Milliseconds an `undoable` write waits for Undo before it is sent; 5000 by default. |

返回 `UseMutationResult<SingleResult<T>, Error, V>`。
