---
title: "useDataProviderName"
description: "useDataProviderName React hook 的签名、参数和返回值。"
---

`explicit`, else the enclosing scope's provider, else undefined (the default).

```typescript
useDataProviderName(explicit?: string): string | undefined
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `explicit` | `string \| undefined` | 否 |  |

返回 `string | undefined`。
