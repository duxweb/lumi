title: "useForgotPassword"
description: "useForgotPassword React hook 的签名、参数和返回值。"

Starts a password reset through `authProvider.forgotPassword`.

```typescript
useForgotPassword(): UseMutationResult<AuthActionResponse, Error, any>
```

返回 `UseMutationResult<AuthActionResponse, Error, any>`。
