---
title: "useFormatCurrency"
description: "useFormatCurrency React hook 的签名、参数和返回值。"
---

Formats an amount in the currency and unit of the i18n `format` config; throws when the provider has no currency format.

```typescript
useFormatCurrency(): (value: number, options?: Intl.NumberFormatOptions) => string
```

返回 `(value: number, options?: Intl.NumberFormatOptions) => string`。
