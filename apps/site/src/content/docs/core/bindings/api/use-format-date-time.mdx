---
title: "useFormatDateTime"
description: "useFormatDateTime React hook 的签名、参数和返回值。"
---

Formats an ISO 8601 UTC string in the time zone of the i18n `format` config; throws when the provider has no datetime format.

```typescript
useFormatDateTime(): (value: string, options?: Intl.DateTimeFormatOptions) => string
```

返回 `(value: string, options?: Intl.DateTimeFormatOptions) => string`。
