---
title: "useFormatDate"
description: "useFormatDate React hook 的签名、参数和返回值。"
---

Formats a date (a Date, a timestamp or a date string) for the current locale, through the i18n provider or `Intl.DateTimeFormat`.

```typescript
useFormatDate(): (value: I18nDateValue, options?: Intl.DateTimeFormatOptions) => string
```

返回 `(value: I18nDateValue, options?: Intl.DateTimeFormatOptions) => string`。
