---
title: "useFormatNumber"
description: "useFormatNumber React hook 的签名、参数和返回值。"
---

Formats a number for the current locale, through the i18n provider or `Intl.NumberFormat`.

```typescript
useFormatNumber(): (value: number, options?: Intl.NumberFormatOptions) => string
```

返回 `(value: number, options?: Intl.NumberFormatOptions) => string`。
