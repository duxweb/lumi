---
title: "useFormatRelativeTime"
description: "useFormatRelativeTime React hook 的签名、参数和返回值。"
---

Formats a relative time such as "3 days ago" for the current locale.

```typescript
useFormatRelativeTime(): (value: number, unit: Intl.RelativeTimeFormatUnit, options?: Intl.RelativeTimeFormatOptions) => string
```

返回 `(value: number, unit: Intl.RelativeTimeFormatUnit, options?: Intl.RelativeTimeFormatOptions) => string`。
