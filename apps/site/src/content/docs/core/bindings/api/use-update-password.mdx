---
title: "useUpdatePassword"
description: "useUpdatePassword React hook 的签名、参数和返回值。"
---

Sets a new password through `authProvider.updatePassword`, e.g. with a reset link's token.

```typescript
useUpdatePassword(): UseMutationResult<AuthActionResponse, Error, any>
```

返回 `UseMutationResult<AuthActionResponse, Error, any>`。
