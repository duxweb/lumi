新建一条记录，成功后刷新这个资源的所有查询。表单保存请用 `submitForm`，它会先等校验通过。

## 用法

```jsonc
{
  "root": "button",
  "elements": {
    "button": {
      "type": "Button",
      "props": { "label": "保存备注" },
      "on": {
        // 点击按钮时执行
        "press": {
          "action": "create",
          "params": {
            // 数据资源名，如 orders
            "resource": "notes",
            // 新记录的字段：标题取自页面状态
            "values": { "title": { "$state": "/draft/title" } }
          }
        }
      },
      "children": []
    }
  }
}
```

## 参数

| 参数 | 说明 | 类型 |
| --- | --- | --- |
| `resource`（必填） | 数据资源名，如 `orders`。 | `string` |
| `dataProviderName` | 使用哪个数据源；省略时用当前范围的数据源，没有就是 default。 | `string` |
| `meta` | 原样传给 DataProvider 的扩展数据。 | `object` |
| `id` | 不使用：新记录的主键由后端分配。 | `string \| number` |
| `values` | 新记录的字段。 | `object` |
| `resultPath` | 把保存结果 `{ data }` 写进页面状态的路径。 | `string` |
