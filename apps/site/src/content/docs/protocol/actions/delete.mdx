删除一条记录，成功后刷新这个资源的查询。`mutationMode` 的含义和 `update` 相同。

## 用法

```jsonc
{
  "root": "button",
  "elements": {
    "button": {
      "type": "Button",
      "props": { "label": "删除" },
      "on": {
        // 点击按钮时执行
        "press": {
          "action": "delete",
          "params": {
            // 数据资源名，如 orders
            "resource": "orders",
            // 要删除的记录主键，必须有值
            "id": { "$state": "/order/id" },
            // 先从列表里拿掉，几秒内可以撤销
            "mutationMode": "undoable"
          }
        }
      },
      "children": []
    }
  }
}
```

## 参数

| 参数 | 说明 | 类型 |
| --- | --- | --- |
| `resource`（必填） | 数据资源名，如 `orders`。 | `string` |
| `dataProviderName` | 使用哪个数据源；省略时用当前范围的数据源，没有就是 default。 | `string` |
| `meta` | 原样传给 DataProvider 的扩展数据。 | `object` |
| `id`（必填） | 要删除的记录主键，必须有值。 | `string \| number` |
| `values` | 不使用：删除不提交字段。 | `object` |
| `resultPath` | 把删除结果 `{ data }` 写进页面状态的路径。 | `string` |
| `mutationMode` | `pessimistic` 等服务器返回，`optimistic` 立即显示，`undoable` 可撤销。 | `"pessimistic" \| "optimistic" \| "undoable"` |
| `undoableTimeout` | `undoable` 模式下等待撤销的毫秒数，默认 5000。 | `integer` |
