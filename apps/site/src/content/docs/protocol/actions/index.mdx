---
title: "动作总览"
description: "页面里能调用的全部动作：读写数据、提示、导入导出、Agent 和导航。"
---

页面通过 `on` 调用这些动作，参数是纯 JSON。每个动作一页，含用法和参数表。

| 动作 | 作用 |
| --- | --- |
| [`login`](/protocol/actions/login/) | 登录，并在完成前清空 Lumi 的查询缓存，上一个账号的数据不会留到新会话里。 |
| [`logout`](/protocol/actions/logout/) | 退出登录，并隔离已缓存的数据，下一个会话读不到。 |
| [`request`](/protocol/actions/request/) | 通过 DataProvider 发一个自定义请求，可以把整理后的响应写进 `resultPath`。 |
| [`create`](/protocol/actions/create/) | 新建一条记录，成功后刷新这个资源的所有查询。 |
| [`update`](/protocol/actions/update/) | 更新一条记录，成功后刷新这个资源的查询。 |
| [`delete`](/protocol/actions/delete/) | 删除一条记录，成功后刷新这个资源的查询。 |
| [`invalidate`](/protocol/actions/invalidate/) | 让一个资源的查询重新请求，用于外部改了数据之后刷新列表。 |
| [`toast`](/protocol/actions/toast/) | 显示一行轻提示（Admin 里在顶部居中），约 3 秒后关闭；`duration` 为 0 时一直显示，同一个 `key` 会原地更新。 |
| [`notify`](/protocol/actions/notify/) | 显示一张通知卡片（Admin 里在右上角），有标题、说明和最多 3 个按钮，按钮执行 Catalog 里的动作后关闭；默认约 4.5 秒后关闭，`duration` 为 0 时一直显示。 |
| [`closeNotice`](/protocol/actions/close-notice/) | 关闭 `notify` 打开的、`key` 对应的通知卡片。 |
| [`exportList`](/protocol/actions/export-list/) | 把符合筛选条件的全部记录导出为 CSV（UTF-8，Excel 可直接打开）或 JSON。 |
| [`importList`](/protocol/actions/import-list/) | 让用户选一个 CSV 或 JSON 文件，逐条通过 create（或按 `batchSize` 通过 createMany）新建记录，被拒绝的行跳过继续。 |
| [`submitForm`](/protocol/actions/submit-form/) | 保存表单：先校验页面状态里的表单值，等业务校验通过，只提交一次，保存成功后才应用 `successState`。 |
| [`agentSend`](/protocol/actions/agent-send/) | 在 `session` 指向的 AgentSession 里发送一条消息。 |
| [`agentStop`](/protocol/actions/agent-stop/) | 停止正在进行的回复，已经收到的内容保留。 |
| [`agentRetry`](/protocol/actions/agent-retry/) | 让 Agent 重新回答最后一条用户消息。 |
| [`agentEvent`](/protocol/actions/agent-event/) | 把 ChatThread 的事件交给会话处理：approve、reject 决定审批，answer、skip 回答问题（没有待回答的就继续回复），regenerate 重试，edit 改写用户消息，suggestion 直接发送建议。 |
| [`navigate`](/protocol/actions/navigate/) | 跳转到一个明确的 Admin 地址。 |
| [`openDrawer`](/protocol/actions/open-drawer/) | 打开一个抽屉或弹窗。 |
| [`closeDrawer`](/protocol/actions/close-drawer/) | 关闭当前这一层抽屉（以及它上面的层），有未保存的改动时先经过离开确认。 |
