# Admin 统一自适应内容宽度

按用户要求统一所有默认页面的宽度，替代列表/仪表盘铺满、普通表单 960px、设置 1120px、发布页 1280px、卡片列表 1440px 的分散规则。

- `LumiPage` 统一居中，默认最大 1280px（包含外层留白），窄屏随可用空间收缩；桌面左右 16px、移动端 12px。
- Spec 路由与五种页面骨架共用默认宽度；设置标题、Tabs、分区、分割线共用同一轴，嵌套页面不叠加留白。
- 宿主可通过 `--lumi-admin-content-max-width` 调整全局上限；显式 `content/full` 保留为自定义页面选项。
- 保留表单、设置和仪表盘原有容器响应式；修正 dashboard 容器选择器对旧 `full` 的依赖。
- 同步设计规范、包 README、生成文档和现有测试。修正 Admin 包内测试的旧 cwd 路径判断。

验证：Admin typecheck/build、改动文件 lint、81 项 Admin 单测、25 项开发服务浏览器用例通过。响应式覆盖 320/768/1440/2560px；视觉和 axe 覆盖 1440/1024/390px × 明暗主题。最后修正 dashboard 容器后复测 4 项 dashboard 用例与 6 项视觉用例全部通过；其中桌面深色用例曾受同时构建清理 CSS 产生的临时 404 影响，构建结束后单独复测通过。

仅更新桌面 tabs 表单明暗两张视觉基线，其余 82 张保持不变；84 张资产清单检查、生成物一致性与 diff 空白检查通过。开发服务继续运行在 http://127.0.0.1:5176/，mock 在 3002。
