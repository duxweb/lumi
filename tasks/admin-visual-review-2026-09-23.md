# Admin 视觉复查与收敛

用户反馈：详情页空白过大、导航图标重复、仪表盘复杂。

## 调整

- 详情移除 Frame 外框与默认 stretch，采用统一 PageHeader 和独立内容卡片。描述、订单项目和活动栏随内容结束；容器不足 880px 时辅助栏下移，无辅助内容时主体占满。
- 字段换行时不再残留竖向分隔线；分区标题改为正文式标题，空属性不渲染空卡片。属性、描述、meta、状态和记录操作保持可用。
- 仪表盘收敛为收入、订单、客户三个指标，一张收入趋势和近期订单表。保留周期、刷新、加载、错误、空数据与图表数据表，提供订单列表入口。
- 模块及菜单采用有区别的语义图标；修复 blocks、pen-line、square-stack 实际复用错误 SVG 的映射。
- 详情页签复用隐藏路由的标题并附记录标识；保留列表导航选中、当前语言解析和仅路径持久化。
- 近期订单表头改用 foreground，满足浅色模式文字对比度。

## 检查范围

实际浏览器复查 Dashboard、商品/订单详情，以及既有列表、表单、设置、组件示例、抽屉和弹窗。当前源码的宽屏页面在 Shell 内对称居中；加入 320 / 768 / 1440 / 2560px 的居中、共享内容轴、详情自然高度和内部滚动回归，未添加推测性的 Shell 位移修正。

使用现有语义 token、HugeIcons 和公开 React 组件，保持 native Spec 与组件目录不变。视觉规范同步至 plan/ui-design-spec.md；基线来自本地实现。

## 验证结果

- `pnpm lint`、`pnpm typecheck`、`pnpm build`、`pnpm check:schema` 通过。
- `pnpm test`：42 个文件、312 项测试通过。最后的空属性卡片调整后补跑 Admin 类型检查、相关 ESLint 和 14 项页面测试通过。
- `pnpm e2e:react-admin --update-snapshots`：40 项通过，覆盖 320–2560px 布局回归，以及桌面、平板、手机的明暗主题截图、axe、业务操作和导航焦点。
- 已人工检查仪表盘、商品/订单详情的新截图，并与列表、表单、设置的共同视觉结构对照；更新相关视觉基线。
